Task 2

Continuing the FastAPI backend from before. Now implement document ingestion.

Task for this step only:
1. Create a POST /upload endpoint that accepts a file (PDF, DOCX, TXT, XLSX, CSV) via multipart form-data
2. Add a document loader module that:
   - Uses PyPDFLoader (or pypdf) for PDF
   - Uses python-docx or Docx2txtLoader for DOCX
   - Reads TXT directly
   - Uses pandas or UnstructuredExcelLoader for XLSX
   - Uses pandas for CSV
3. Chunk the extracted text using LangChain's RecursiveCharacterTextSplitter (chunk_size=500, chunk_overlap=50)
4. Embed chunks using HuggingFace all-MiniLM-L6-v2 and store them in a FAISS vector store, scoped per uploaded file/session (use a unique session_id or file_id)
5. Return a JSON response confirming file processed, number of chunks created, and the session_id/file_id to use for querying

Do not implement the chat/query endpoint yet. Just uploading and indexing. Test with one sample file of each type and show me the output.
